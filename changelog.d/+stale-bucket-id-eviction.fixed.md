Drop a cached bucket name-to-id entry as soon as the server reports the id as gone (a `bad_bucket_id` error, or an empty `b2_list_buckets` result for that id or name), and when `B2Api.delete_bucket` succeeds. A bucket deleted or recreated from elsewhere (web UI, another machine, an infrastructure tool) is now resolved correctly on the next lookup by name instead of failing until the cache is reset by hand.
